# JARVIS

JARVIS is an open-source AI-powered personal media management system.

It manages media stored across multiple storage providers such as Telegram, NAS, external HDDs, and cloud storage.

It does not replace Jellyfin.
It complements Jellyfin by managing uploads, storage, migration, integrity verification, metadata, and AI-powered search.

Long-term goals:
- Telegram uploader
- Storage abstraction
- AI recommendations
- NAS migration
- Multi-user support
- Open source
